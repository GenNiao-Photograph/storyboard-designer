# storyboard-designer · AI 视频分镜表设计

> 把旁白 / 剧本，变成一份能直接用来做 AI 视频的标准化分镜表。

## 这是什么

> **storyboard-designer —— 一个方便客户 / 甲方 / 领导审核、减少返工、提高效率、便于对齐颗粒度的技能。**

`storyboard-designer` 是一个面向 **AI 视频（首尾帧提示法）** 的通用 Agent 技能，任何支持技能调用的 AI 工具都能使用。你给它一段旁白文案或剧情脚本，它就会：

1. 判断全片画面风格；
2. 把剧中的人物 / 道具 / 场景做成「形象设计」；
3. 切分旁白、算好每镜时长、排好景别；
4. 为每一镜写出首帧 / 尾帧画面提示词与首尾帧动态提示词；
5. 渲染成一份规范排版的 `.xlsx` 分镜表。

好处是：**形象一致、镜头连贯、节奏可控、能直接拿去生成视频**，不用每条都对着一堆提示词东拼西凑；同时把创意、画面、脚本在前期一次对齐，**降低 token 成本与人力成本**，减少反复生成和返工。

## 建议的完整工作流（从剧本到交付）

这个 skill 定位在整条 AI 视频流水线里的「分镜表制作」一环。建议按下面顺序推进，并在关键节点让客户 / 甲方 / 领导过一遍，避免做到后面才发现方向不对：

1. **剧本文案撰写** —— 先定内容与口播。
2. **领导 / 客户审核** —— 确定核心方向（讲什么、面向谁）。
3. **分镜表制作** —— 用本 skill 生成「分镜表 + 形象设计」。
4. **形象图设计** —— 用 AI 生图工具，按形象设计提示词生成人物 / 道具 / 场景图。
5. **领导 / 客户审核** —— 确定画面风格（人物长相、道具、场景是否统一）。
6. **生成首尾帧并导入分镜表** —— 按提示词生成首帧 / 尾帧，回填到 Excel。
7. **领导 / 客户审核** —— 确定画面「感觉」。
8. **生成 AI 视频** —— 按首尾帧 + 动态提示词生成片段。
9. **剪辑** —— 拼装、加旁白与音效、控制节奏。
10. **领导 / 客户提修改意见** —— 指出要改的镜头。
11. **优化** —— 针对性重生成 / 微调。
12. **交付**。

> 每一步都产出可审的「颗粒度」交付物（分镜表、形象图、成片），让审核有据可依，把返工尽量前置到早期。

## 为什么做（解决什么问题）

用 AI 工具（文生图 + 图生视频）做短片时，常见痛点是：

- 每一镜的提示词措辞不一致，人物长相、服装、场景风格前后对不上；
- 没有统一风格，画面像「拼出来的」；
- 旁白和画面长度对不上，节奏忽快忽慢；
- 到生成阶段才发现某镜缺尾帧、缺少运动描述，返工成本高。

这个 skill 把「**先定形象、再写分镜**」的流程固化下来，让你在动手生成前就拿到一份可执行的蓝图。

## 核心概念：首尾帧提示法

当前主流 AI 视频生成有两种思路：

- **单图生成**：一张参考图 + 一段运动提示词，适合画面变化小、近乎静态的镜头。
- **首尾帧生成**：首帧 + 尾帧两张图 + 动态提示词，用两端约束中间的运动，适合有明显动作 / 运镜 / 内容变化的镜头。

`storyboard-designer` 主要针对后者，并会在合适的镜头自动切换成**单图生成**。

## 功能亮点

- **风格库**（`references/style-library.md`，持续更新中）：内置「实拍类」与「MG 二维平面动画类」共 11 种不同风格，按题材挑取，全片统一。
- **运镜库**（`references/camera-library.md`）：100 条运镜 / 动态描述，分 7 类。写动态提示词时**只借手法、结合画面重写**，不逐字照搬。
- **形象提示词公式**：`风格描述 + 形象描述 + 固定话术（多视图 / 九宫格）`，人物用多视图角色设计板、道具用九宫格、场景用全景描述。
- **景别渐进**：相邻镜大 → 中 → 近 → 特，避免跳级。
- **旁白合并**：一句旁白对应多个画面时自动合并单元格。
- **单图生成**：内容变化小、无大幅运镜的镜头自动降级为单图，并浅灰标记尾帧列。
- **图片列留空**：首帧画面 / 尾帧画面 / 形象图一律留空，由你在外部 AI 工具里生成后填入。

## 工作流程（8 步）

1. **定风格**：读旁白 / 脚本题材，按风格库挑选大类与子风格，全片统一。
2. **建形象设计表**：遍历人物 / 道具 / 场景，建立唯一资产名称与提示词。
3. **切分旁白并算时长**：按语义切分（一句开头尽量 ≤14 字），时长按语速估算，封顶 7 秒。
4. **划分分镜**：每镜写「画面内容」（谁、在哪、做什么），控制景别渐进。
5. **写提示词**：写首帧 / 尾帧提示词、首尾帧动态提示词与音效；必要的镜头改用单图生成。
6. **尾帧接首帧**：高连贯处下一镜首帧写「同上一画面尾帧」，总数 ≤ 全片 1/6。
7. **渲染 Excel**：用脚本把内容渲染成 `.xlsx`。
8. **交付**：报告文件路径、分镜数、资产数，以及采用 / 新增的风格与特殊设定。

## 输入 / 输出

### 输入

至少要给出**旁白文案 / 剧情脚本**。可选：画面风格要求、景别偏好、角色 / 道具 / 场景设定、音效备注。

### 输出

一份 `.xlsx`，含两个子表：

| 子表 | 列 |
| --- | --- |
| **分镜表** | 镜号、时长(秒)、画面内容、首帧画面提示词、首帧画面、尾帧画面提示词、尾帧画面、首尾帧动态提示词、旁白、音效 |
| **形象设计** | 序号、名称、提示词、形象图 |

首帧画面 / 尾帧画面 / 形象图三列留空，由你在外部 AI 视频工具生成后回填。

## 使用方法

### 直接调用

把旁白 / 剧本发给任意支持技能的 AI agent，并引用本 skill 即可。例如：

> 使用 storyboard-designer 为这段旁白生成 AI 视频分镜表。

### 手动渲染

按 `references/excel-format.md` 的 `storyboard.json` 结构填好数据，运行：

```bash
python scripts/build_storyboard.py --input storyboard.json --output 分镜表.xlsx
```

脚本只负责排版（表头加粗、冻结首行、列宽、行高、单图浅灰标记、旁白合并），提示词等内容由你 / agent 生成。

## 判断规则速览

- **时长**：`≈ round(字数 × 0.3)`，单镜封顶 7 秒。
- **景别**：远景 / 全景 / 中景 / 近景 / 特写，相邻镜渐进，不跨级。
- **单图生成**：主体基本不动、无大幅运镜、内容几乎无变化的镜头。
- **尾帧接首帧**：高连贯处用，≤ 全片 1/6。
- **旁白合并**：一句旁白对应多镜时合并单元格。

## 已知边界与取舍

- 规则是「合理渐进」而非教条；为表达连贯动作允许特殊长句、景别微调，但要在交付说明里标注。
- 图片列需在外部工具生成后回填，本 skill 不生成图片，也不负责具体视频。
- 时长公式按默认语速估算：若目标成片时长很紧，需要按目标秒数调整或精简口播。

## 快速示例

给出一句旁白（示例）：

> 孩子入园入学，就要开始集体生活。

会生成类似下面的分镜行（节选）：

| 镜号 | 时长 | 画面内容 | 首帧画面提示词 | 尾帧画面提示词 | 首尾帧动态提示词 |
| --- | --- | --- | --- | --- | --- |
| 05 | 4 | 全景，校园集体生活场景，入学萌娃走进操场。 | 全景，明亮卡通校园集体生活场景，入学萌娃背着书包走进操场。 | 全景，操场上有几位小朋友在追逐玩耍，萌娃融入其中，气氛热闹。 | 镜头横向平移扫过操场，萌娃走向小朋友群，画面由安静转热闹。 |

形象设计里会先把这个「入学萌娃」用**多视图角色设计板**固定下来，之后每一镜都只引用它，保证前后一致。
