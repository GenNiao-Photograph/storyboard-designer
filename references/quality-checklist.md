# 通用质量标准

这份清单用于每次分镜、旁白和提示词交付前的自检。以下四类问题最容易造成返工。

## 1. 叙事与旁白

### 先定叙事视角

- 先确定第一人称、第三人称或全知视角，并在全片保持一致。
- 不要因为追求情绪就擅自切换人称；需要切换时，必须有明确的叙事理由。
- 第三人称也可以有情绪，但情绪应来自具体动作、物件、光线和停顿，而不是解释性形容词。

### 保留必要信息

- 人物身份、关系、目标、关键因果和转折不能为了“简洁”而删除。
- 观众第一次认识主角时，应能获得足够的身份锚点：是谁、处于什么生活状态、为什么值得继续看。
- 删除的是重复解释和顺拐衔接，不是叙事信息本身。

### 旁白与画面分工

- 旁白负责情绪、内心、时间压缩和转场。
- 画面已经清楚表达的动作，不要用旁白逐字复述。
- 少用“于是”“就这样”“后来她……”这类纯连接句；优先用画面、动作或对白完成过渡。
- 每句旁白都要能自然朗读；避免过长定语、并列堆叠和书面腔。

### 对白要有来有回

- 关键关系节点至少让两个角色产生真实回应，不能只有主角一个人在说。
- 对白应推动关系、暴露态度或改变决定，而不是重复旁白。
- 对白用“角色：台词”标注；同一镜内多人对话用换行分隔。
- 旁白和对白交替出现时，要让对白承担“现场感”，旁白承担“回望感”。

### 情感曲线

- 开头建立状态，中段出现触发事件，后段发生选择或变化，结尾回扣主题。
- 情绪要有递进，不要每一句都用同样的强度。
- 适当保留无旁白的呼吸镜头，让观众自己感受画面。

## 2. 时长与分镜

### 先定预算

- 先确定目标总时长和大致镜头数，再写分镜。
- 平均镜头时长 = 总时长 ÷ 镜头数；对白镜头、情绪镜头可以更长，过渡镜头可以更短。
- 单镜默认不超过 7 秒；对白镜头要给足呼吸，不能把两句长台词硬塞进 3 秒。

### 压缩优先级

需要缩短时，优先删：

1. 重复的氛围镜头和空镜；
2. 只起连接作用、没有新信息的过渡镜头；
3. 不推动关系或选择的支线；
4. 重复表达同一情绪的旁白。

不要删：

- 主角身份介绍；
- 关键因果和人物动机；
- 核心对白和关系转折；
- 结尾的主题回扣。

### 节奏

- 情绪建立可以用 3–5 秒的镜头，对白可以用 4–7 秒，纯过渡可以 2–3 秒。
- 景别按“大→中→近→特”或反序渐进，避免全景直接跳特写。
- 压缩后要重新检查镜头之间的语义连接，不能只改时长不改分镜。

### 版本管理

- 长版、短版、不同风格版本分开保存，不要覆盖上一版。
- 文件名应体现版本差异，例如“完整版”“2分30秒版”“动画版”“某风格版”。

## 3. 提示词可执行性

### 单条可读

- 每条首帧、尾帧和动态提示词都要能单独复制使用，不能依赖“同上”“同上一画面”或前文语境。
- 如果工具支持首尾帧引用，可以使用技术性的“同上一画面尾帧”，但必须确认工具能读到上一帧；面向文本生图时要写全。

### 用资产名，而不是重复外观

- 已经有角色、道具、场景资产时，分镜提示词用唯一资产名引用，例如“角色 A（阶段一）”“角色 A 的手机”“场景 B”。
- 不要在每条分镜里重复角色的年龄、发型、服装、五官；外观由形象设计资产负责。
- 只有当资产没有参考图、或工具只接受纯文本时，才补最小必要的外观锚点。

### 概念要能独立理解

- 虚构 App、行业黑话、缩写和平台名第一次出现时，用一句短语解释其现实对应物。
- 例如“某虚构社区 App，类似图文笔记平台”，而不是只写一个无法识别的名字。
- 不要把“海报”“日签”“帖子”混用；要说明它是实体物、手机页面、社媒帖子还是聊天消息。

### 数字界面与实体物分开

- 手机里的页面要写明“手机屏幕内显示”“数字页面”“无纸张厚度、无桌面投影”。
- 实体卡片才写纸张、厚度、阴影、桌面摆放。
- UI 提示词要写清设备、屏幕方向、分格方式、界面层级和关键文字；不要用“九宫格”描述本应是四宫格或单页界面的内容。

### 镜头提示词结构

- 首帧/尾帧：景别 + 资产名 + 场景 + 动作/神态 + 关键道具。
- 动态提示词：运镜 + 主体动作 + 状态变化 + 景别变化（如有）。
- 避免互相矛盾的约束，例如画面里有人物却写“无人物”，或画面里有手机支架却写“无手机支架”。

### 文字与界面

- 画面内文字尽量短；长段文字、复杂 UI 文案建议后期叠加。
- 需要精确文字时，明确写出文字内容和位置；不需要时，说明“文字区域留白”。

## 4. 人物一致性

### 先定面部基准

- 先建立一个角色的面部基准资产，再生成其他阶段。
- 后续阶段必须明确引用同一张脸、同一骨相、同一五官比例。
- 文字描述与参考图冲突时，以参考图的人脸为准。

### 阶段变化只改允许的维度

- 允许改变：发型、妆容、服装、体态、皮肤状态、神态、光线。
- 不允许改变：骨相、五官比例、眼距、鼻型、唇形、脸型、年龄感和身份特征。
- 皮肤和体态可以有阶段提升，但要保留真实年龄感和自然纹理，避免医美脸、过度磨皮和过度瘦脸。

### 服装变化做成独立资产

- 同一角色换装时，建立“角色（阶段/服装）”资产，而不是在每个镜头里重复描述服装。
- 资产名统一使用“角色（阶段）”格式，避免“角色·阶段”这类容易混淆的命名。
- 分镜引用资产名时必须逐字一致。

### 身体与比例

- 同一角色的身高、骨架和体型比例应保持一致；除非剧情明确要求变化，否则不要在每个阶段重新设计身体。
- 多视图角色板中的全身视图、头像和细节图必须使用同一张脸、同一发型、同一服装。

### 角色之外的道具也要一致

- 手机、日签、海报、群聊界面等反复出现的道具也要建立资产。
- 分镜里用资产名引用，不要每次写“黑色手机”“绿色卡片”这类容易漂移的描述。
- 数字页面、手机外壳、实体卡片要分清；页面显示在手机上时，手机外观引用手机资产。

## 5. 交付前自检

- [ ] 旁白连起来读是否自然？是否保留了人物介绍和关键因果？
- [ ] 对白是否有来有回，而不是只有主角台词？
- [ ] 总时长是否达到目标？压缩后是否仍保留主线和结尾回扣？
- [ ] 每条提示词是否单独可读？是否还在依赖“同上”或前文？
- [ ] 人物外观是否用资产名引用，而不是每镜重复描述？
- [ ] 主角各阶段是否引用同一面部基准？服装变化是否有独立资产？
- [ ] 手机、日签、帖子、群界面等道具是否引用资产？
- [ ] 数字页面和实体物是否分清？UI 分格方式是否符合需求？
- [ ] 是否还有互相矛盾的提示词约束？
- [ ] 风格是否落实到全部资产，而不是只写在标题里？
