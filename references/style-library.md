# 风格库

此文件是**画面风格库**，存放本 skill 会用到的可复用「风格限定描述」。内容整理自对常见 AI 视频风格的归类，并**合并同类项**：按「实拍类」与「MG 二维平面动画类」两大分支组织；MG 类里把「6 小分类」与「4 张图归纳」重叠的条目合并，只保留视觉语言明显不同的子风格。

优先级标记：`✅`=推荐（安全、通用），`⚠️`=谨慎（有局限，只用于特定片段/题材）。

## 使用规则

1. **判定风格**：先读**用户描述**（画面风格要求）+ **旁白/脚本题材**（科普？宣传？叙事？文化？还是纯逻辑？）→ 判断「要传达什么、面向谁」→ 从本库选一条最贴合的风格。库里有则直接引用；没有则由你根据用户要求提炼一句风格描述，并提示可加入风格库。
2. **题材快速对应的挑选方向**：
   - 企业宣传 / B端 / 政策 / 流程 / 数据 → 实拍·电影级写实 或 MG·极简商务矢量 / 商务信息图解
   - 硬核技术 / 系统架构 / 空间 / 工业流程 → MG·等距 2.5D
   - 文化 / 非遗 / 国风 / 文旅 → MG·新国潮 或 轻肌理绘本（成人档）
   - 少儿 / 亲子 / 教育 / 校园 / 情感叙事 → MG·轻肌理绘本（Q版/半Q档）或 少儿明亮扁平
   - 知识科普、逻辑清晰、信息传达 → MG·极简商务矢量 / 商务信息图解（优先）
   - 严肃正式、真实可信 → 实拍·纪录片纪实 / 电影级写实
   - 片头、片尾、概念引入、转场背景 → MG·几何抽象符号（点缀，不做主体）
3. **风格一旦确定全片统一**：风格描述并入形象设计提示词，因此**分镜画面提示词不再重复堆砌风格**。
4. **形象提示词组成（固定）**：`风格描述 + 形象设计描述 + 固定话术（多视图 / 九宫格）`。风格描述取本库该条的「风格描述」字段；形象设计描述写该资产的唯一外观；固定话术按资产类型套用（人物→多视图角色设计板，道具→9宫格，场景→全景描述，见 [形象设计](asset-design.md)）。

## 大类一：实拍类（写实）

> 共性：信息清晰、真实可靠、不喧宾夺主。宣传片 & 科普主力，✅优先推荐。

### 电影级写实商业实拍风（✅优先）
风格描述：`4K，商业实拍，柔和电影布光，浅景深，平稳运镜，自然真实材质，干净画面，低饱和度，专业广告摄影`
画面特征：电影布光、暖冷均衡柔和；浅景深；推拉摇移平稳；真实材质；色彩克制高级；无夸张特效；关闭强艺术滤镜。
适用：企业宣传片、产品演示、科普实景还原、城市宣传片、机构介绍。
风险：人物五官易崩坏、手部畸形。屏蔽词：强艺术滤镜、卡通、插画质感、高饱和饱和。

### 微距写实科学纪实风
风格描述：`微距摄影，科学纪实，实验室冷白光，高细节，客观写实，干净背景，4K`
画面特征：微距镜头；微观物质、细胞、流体、材质特写；明亮实验室光照；细节清晰干净。
适用：理化科普、生物科普、材料科学短片。
风险：易生成过度科幻异化的生物；强调「科学纪实，忠于现实」。屏蔽词：科幻异化、发光特效。

### 纪录片纪实风格
风格描述：`纪录片摄影，自然日光，轻微手持呼吸感，中性色调，纪实叙事，真实场景`
画面特征：自然光影；轻微手持呼吸感；色调中性；真实场景；不夸张；叙事感强。
适用：人文科普、纪实向宣传片、案例故事短片。

## 大类二：MG 二维平面动画类（动态插画）

> 共性：信息传达效率极高，适合短视频科普，大众接受度高；知识科普短视频爆款主力。下列各子风格视觉语言明显不同，按题材选用。

### 极简商务矢量 MG（✅最高优先，通用万能）
风格描述：`MG动画，极简商务矢量插画，无纹理，干净硬边图形，大圆角，无粗轮廓线，莫兰迪商务低饱和配色，二维平面动画，平滑弹性运动，简洁符号化人物，干净白底/浅灰底，商业科普动画，4K`
画面特征：纯矢量、无画笔肌理；干净硬边图形；大量圆角；线条极细或无轮廓线；平面二维无透视；运动干净利落、形变柔和；无多余装饰。
适用：业务流程演示、政策解读、逻辑科普、企业介绍、数据图表动画、短视频知识讲解。
风险：AI 易加描边、多余纹理、卡通大眼人物；人物尽量简化符号化，避免写实五官崩坏。屏蔽词：粗黑描边、手绘肌理、涂鸦、Q版大头、大眼睛、卡通、噪点、纹理、阴影过重。

### 商务信息图解细线剪影 MG（✅B端逻辑首选）
风格描述：`商务信息图解MG，细线矢量插画，人物剪影，无面部五官，信息图表，箭头标注，商务低饱和配色，网格背景，平涂色块，逻辑演示`
画面特征：极细单色工程矢量描边，无手绘；人物用标准 7 头身写实剪影、完全省略五官；图表、箭头、标注文字是画面核心；大面积白底网格；颜色严格服务信息区分；零肌理，100% 矢量线条。
适用：财经科普、政策解读、法律科普、B端企业业务流程讲解。
风险：没有情绪感染力，只适合讲逻辑，不适合叙事。屏蔽词：Q版、大眼睛、绘本肌理、鲜艳马卡龙色。

### 轻肌理绘本插画 MG（✅人文 / 文化 / 教育）
风格描述：`动态商业扁平插画MG，微弱纸张肌理，干净图形轮廓，柔和渐变，低饱和柔和配色，平滑二维动画，干净背景`（人物比例按题材选档）
画面特征：扁平化形体、清晰图形边界；叠加极淡纸张/粉笔肌理（非厚手绘）；柔和渐变；轮廓细；色彩柔和丰富；质感温暖高级、不幼稚。
人物比例分三档（择一）：**Q版档**（2–2.5 头身、大头圆眼、腮红，马卡龙柔暖色）→ 亲子/少儿；**半Q档**（3 头身、细轮廓、复古暖大地色、情绪化表情）→ 校园/叙事；**成人档**（简约优雅成年人形象）→ 人文/科普。
适用：人文科普、健康科普、社会议题、文旅短片、教育短视频、品牌故事片段、亲子/少儿科普。
风险：AI 易把肌理做过重变成儿童绘本或低幼画风；严格控制「微弱肌理」。屏蔽词：厚重笔刷、厚涂、涂鸦、粗轮廓、夸张表情；成人档再加：儿童绘本、Q版大头。

### 少儿宣传向明亮扁平 MG（✅少儿 / 公益，⚠️不宜严肃）
风格描述：`纯矢量扁平MG动画，3.5头身卡通人物，清晰中等粗细轮廓线，平涂色彩，高亮度清爽配色，无手绘肌理，装饰性矢量图形，欢快动态人物`
画面特征：清晰中等粗细的矢量轮廓线；纯矢量平涂、零肌理；高亮清爽饱和色；眼睛简化、五官概括、表情明快；人物姿态动感强（可跳跃奔跑）；大量装饰性矢量元素（彩虹、水花、彩旗、空白标题框）。
适用：少儿文旅宣传、公益少儿科普、活动海报、宣传片片头。
风险：色彩偏鲜亮，不适合严肃政策、硬核技术科普。屏蔽词：纸张肌理、绘本笔触、暗沉色调。

### 等距 2.5D 扁平化 MG（✅技术 / 空间 / 流程 / 建筑）
风格描述：`等距2.5D MG动画，isometric，扁平化矢量插画，轴测视角，圆角几何体，柔和浅投影，干净无复杂材质，二维动态，系统流程演示，浅灰背景`
画面特征：等距轴测视角、2.5D 扁平化图形；无透视畸变；圆角几何体；干净矢量；浅投影；不做真实 PBR 材质。
适用：工业流程科普、系统架构讲解、城市规划、物流链路、产品结构演示、数字化宣传片。
风险：AI 易生成真实 3D 渲染、金属反光；强调「扁平化矢量，不是三维渲染」。屏蔽词：C4D渲染、PBR材质、金属反光、强光影、写实三维、复杂纹理。

### 新国潮扁平化 MG（✅文化 / 非遗 / 国风）
风格描述：`新国潮MG动态插画，现代扁平化矢量，简约传统纹样，雅致国风低饱和配色，干净二维动画，少装饰，留白，4K科普动画`
画面特征：扁平化矢量图形；少量传统纹样装饰；低饱和国风配色（青、黛、赭石）；线条干净，拒绝老动画质感。
适用：传统文化科普、非遗、文旅宣传片、国风主题短片。
风险：易做得很土、老动画质感、元素堆砌。屏蔽词：老动画、老旧画质、浓艳大红大绿、元素堆砌、手绘厚涂。

### 细线描边扁平化 MG（⚠️谨慎，片段点缀，不做全篇）
风格描述：`细线描边扁平MG动画，统一细轮廓线，简洁几何图形，克制配色，平滑动画，符号化人物，干净背景`
画面特征：所有图形统一细黑/深色描边；扁平填色；图形简洁；动画轻快。
适用：短视频科普片段、短视频切片；适合片段，不建议完整企业宣传片全篇使用。
风险：极易滑向儿童动画；描边易粗细抖动；人物易 Q 版化。屏蔽词：粗描边、卡通大头、Q版、夸张表情、鲜艳高饱和、涂鸦。

### 几何抽象符号 MG（⚠️谨慎，片头 / 转场 / 氛围）
风格描述：`抽象几何MG动画，简约色块线条，平滑动态，商务氛围感，浅纯色背景`
画面特征：几乎无具象人物物体，只用几何图形、线条、色块动态演绎概念；表达能量、连接、抽象概念。
适用：宣传片片头片尾、转场、开篇概念引入；不能用来讲具体知识内容。
风险：信息传达弱、不易看懂，只适合氛围。屏蔽词：迷幻、流体畸变、高饱和炫彩。
