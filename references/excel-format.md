# Excel 格式

产出是一个 `.xlsx`，包含两个子表，顺序为「分镜表」在前、「形象设计」在后。

## 分镜表（子表 1）

表头（第 1 行）与列：

| 列 | 表头 | 说明 |
| --- | --- | --- |
| A | 镜号 | 两位零填充，如 `01`、`02` |
| B | 时长(秒) | 整数 |
| C | 画面内容 | 谁、在哪、做什么 |
| D | 首帧画面提示词 | 文生图提示词 |
| E | 首帧画面 | **留空**（用户填图） |
| F | 尾帧画面提示词 | 文生图提示词 |
| G | 尾帧画面 | **留空**（用户填图） |
| H | 首尾帧动态提示词 | 图文生视频提示词 |
| I | 旁白 | 可合并 |
| J | 音效 | 音效描述 |

**旁白合并**：一句旁白对应多个分镜时，将这些行的「旁白」列（列 I）**合并为一个单元格**，旁白文字放在合并区域内第一行。其余行该列为空。

**单图生成**：某镜改用「单图生成」时，该行「尾帧画面提示词」（列 F）写 **「同首帧（单图生成）」**，「尾帧画面」（列 G）留空；脚本会把这一镜的尾帧两列以浅灰底标注，提示该镜不设尾帧。判断标准见 [分镜规则](storyboard-rules.md)。

## 形象设计（子表 2）

| 列 | 表头 | 说明 |
| --- | --- | --- |
| A | 序号 | 整数，从 1 |
| B | 名称 | 全片唯一的资产名称 |
| C | 提示词 | 风格+形象描述+固定话术 |
| D | 形象图 | **留空**（用户填图） |

## 建议格式

- 首行表头：加粗、深色填充、白字，居中，冻结首行。
- 正文：文字自动换行、垂直居中、左对齐；不同分镜间可用浅色隔行或边框。
- 列宽参考：镜号 6、时长 6、画面内容 28、首帧/尾帧提示词 40、首帧/尾帧画面 20、动态提示词 40、旁白 20、音效 24；形象设计：序号 6、名称 26、提示词 60、形象图 20。
- 行高：按内容自适应，至少能显示 1–2 行文字。

## 脚本用法

用随附脚本渲染（脚本只负责排版，提示词等内容由你生成后填入）：

```bash
python scripts/build_storyboard.py --input storyboard.json --output 分镜表.xlsx
```

若系统 `python` 未安装 `openpyxl`，改用本环境绑定的 Python 运行时运行（见
`load_workspace_dependencies` 提供的路径），或先安装 `openpyxl`。

`storyboard.json` 结构：

```json
{
  "project_name": "项目名称",
  "style_name": "风格名",
  "style_description": "一句风格限定描述",
  "assets": [
    {"index": 1, "name": "资产唯一名称", "prompt": "提示词", "image": ""}
  ],
  "shots": [
    {
      "index": 1,
      "mode": "first_last",
      "duration": 4,
      "scene_content": "谁在哪做什么",
      "first_frame_prompt": "首帧提示词",
      "last_frame_prompt": "尾帧提示词",
      "motion_prompt": "动态提示词",
      "narration": "旁白",
      "narration_span": 1,
      "sfx": "音效"
    }
  ]
}
```

字段说明：

- `mode`：`first_last`（默认，首尾帧）或 `single`（单图生成）。`single` 时若 JSON 未提供 `last_frame_prompt`，脚本会自动写成「同首帧（单图生成）」，并浅灰标记尾帧两列。
- `narration_span`：本旁白横跨的分镜行数（默认 1）。`>1` 时脚本会把「旁白」列这几行合并，旁白文字放在第一行；其余行 `narration` 留空。
- `image`：始终留空串（首帧画面/尾帧画面/形象图由用户后填）。
- `style_name`/`style_description`：用作交付说明，也会在 Excel 顶部或备注中呈现（如需要）。
